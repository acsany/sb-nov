Using these commands in your terminal

In the project folder, run uv sync once, then prefix commands with uv run, for example uv run secondbrain list. You can also use uv run python -m secondbrain list.

new takes a title and accepts --body TEXT or -b TEXT. Use --body - to read from standard input, as in cat draft.md | uv run secondbrain new "Draft" --body -.

Notes go to ~/secondbrain/ by default. Set SECONDBRAIN_DIR to use another folder. Run uv run secondbrain --help or uv run secondbrain new --help for usage.
